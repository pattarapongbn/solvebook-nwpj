# หน้าร้าน (storefront)

หน้าสั่งซื้อของลูกค้า เป็นไฟล์ static ล้วนที่อยู่ใน `public/` ของ Next.js app
จึงถูก deploy ขึ้นไปพร้อมกันในโปรเจกต์เดียว ไม่ต้อง host แยก

เปิดที่ `https://<โดเมนของคุณ>/shop/` — ลิงก์นี้แหละที่เอาไปแปะในแอด

```
public/shop/
  index.html          หน้าร้านทั้งหมด (~100 KB)
  addresses.json      ฐานตำบล/อำเภอ/จังหวัด 7,498 แถว — โหลดตอนลูกค้าเริ่มค้นที่อยู่
  img/slide-*.jpg     รูปสไลด์ (รูปแรกโหลดทันที ที่เหลือ lazy)
  vendor/jsqr.min.js  อ่าน QR บนสลิปในเครื่องลูกค้า (jsQR 1.4.0, MIT)
```

> เดิมทุกอย่างฝังรวมในไฟล์เดียว 1.9 MB ซึ่งช้ามากบนมือถือ 4G — คนที่กดมาจากแอด
> ต้องเห็นหน้าเร็ว ไม่งั้นเสียค่าคลิกฟรี จึงแยกรูปกับฐานที่อยู่ออกมาเป็นไฟล์ต่างหาก

## ชี้ไป backend

ค่าเริ่มต้นคือ `window.SCOUT_API_BASE = ""` แปลว่าเรียก API ที่โดเมนเดียวกับหน้านี้
ซึ่งถูกต้องอยู่แล้วเวลา deploy ขึ้น Vercel พร้อมกัน

ถ้าเอาหน้านี้ไปวางคนละที่กับ backend ให้แก้เป็นโดเมนเต็มใน `index.html`
(อย่าลืมใส่โดเมนหน้าร้านใน `CORS_ORIGINS` ของ backend ด้วย)

ถ้าลบบรรทัดนั้นทิ้ง หน้าเว็บจะเข้า **โหมดออฟไลน์**: สั่งซื้อและสร้าง QR ได้
แต่ไม่บันทึกออเดอร์จริง ไม่กันสลิปซ้ำ — ใช้พรีวิวเท่านั้น ห้ามใช้ขายจริง

## ขั้นตอนที่หน้าเว็บทำ

1. ลูกค้ากรอกที่อยู่ (ค้นจาก `addresses.json`)
2. `POST /api/v1/orders` → backend คืน `amount_due` (ยอด + เศษสตางค์ไม่ซ้ำ) กับ `promptpay_payload`
3. หน้าเว็บ render QR จาก payload ที่ backend ส่งมา ลูกค้าสแกนแล้วยอดเด้งมาเป๊ะ
4. ลูกค้าแนบสลิป → **อ่าน QR ในเครื่องลูกค้า** + คำนวณ SHA-256 ของไฟล์
5. `POST /api/v1/orders/{code}/slip` ส่ง `qr_payload`, `image_hash` และรูปสลิป (base64)
   - `qr_ok` → ผ่าน
   - `duplicate` → บล็อกไม่ให้กดยืนยัน ต้องแนบใบใหม่
   - `qr_unreadable` → **ผ่านได้** แต่ flag ไว้ให้แอดมินเปิดรูปดูเอง

## ที่ยังไม่ได้ทำ

`addresses.json` มีแค่ `[ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์]` **ยังไม่มีรหัสราชการ**
(tambon_code 6 หลัก / amphoe_code 4 หลัก / province_code 2 หลัก)

ฝั่ง backend รองรับแล้ว (คอลัมน์มีครบ เป็น nullable และ `AddressInput` รับค่าได้)
เหลือแค่เปลี่ยน `addresses.json` เป็นชุดที่มีรหัส แล้วส่งเพิ่มใน `createOrder()`
ควรทำก่อนต่อ Shippop/Flash เพราะชื่อไทยสะกดได้หลายแบบจนขนส่ง map ไม่เจอ

## ทดสอบในเครื่อง

```bash
cd frontend/public/shop && python3 -m http.server 8080
# เปิด http://localhost:8080/index.html
# จะเข้าโหมดออฟไลน์ถ้าไม่มี backend ที่ origin เดียวกัน
```
